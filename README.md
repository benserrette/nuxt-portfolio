## Portfolio Content

This site showcases a mix of software engineering work and illustration projects.
Each project lives in the `pages/` directory and is referenced in
`assets/pages_data.js`. Below is a brief overview of the featured content.

### Software Projects

- **VaporBot** – Python scripts that generate "robowave" tracks and post them to
  YouTube and Spotify automatically.
- **The Stache** – Comedy adventure game created with RPG Maker about finding a
  missing mustache.
- **Enso** – A research survey tool that gamifies the collection of social
  network data.
- **OSoMe** – Observatory on Social Media, a suite of tools for studying and
  visualizing social media data and misinformation.
- **Hoaxy** – Web app for tracking the spread of articles online using Twitter
  and fact‑checking data.
- **CADRE** – Collaborative Archive & Data Research Environment built on AWS for
  large research datasets.
- **Shake It Tarot** – Android app that lets users draw tarot cards by shaking
  the phone.
- **CAM** – Conference Agenda Manager that helps attendees build custom
  schedules.
- **Infinite Canvas 2.0** – 2010 masters capstone exploring digital infinite
  canvas storytelling.

### Illustration & Comics

- **An Illustrated Guide to Programming** – Full‑color book introducing
  programming concepts to absolute beginners.
- **IMLS Video** – Animated introduction video for the CADRE project.
- **Captain Numbskull** – Comic book about a hapless space pirate, funded via
  Kickstarter.
- **Comics** – Collection of web comics including *Toilet Humor and Dick Jokes*,
  *Strips 4 Singles*, *24 Hour Comic Day 2014*, and the archive of *Poonheads*.

## Build Setup

```bash
# install dependencies
$ npm install

# serve with hot reload at localhost:3000
$ npm run dev

# build for production and launch server
$ npm run build
$ npm run start

# generate static project
$ npm run generate
```

For detailed explanation on how things work, check out [Nuxt.js docs](https://nuxtjs.org).
